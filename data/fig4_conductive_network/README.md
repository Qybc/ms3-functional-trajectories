# Figure 4 conductive-network data

This directory contains the raw electrical workbooks underlying the displayed
CNT/CB single-layer and CNT/CB--Ag dual-layer traces. Three independently
fabricated devices were tested per architecture; the released workbooks
correspond to the representative devices shown in the main figure.

`representative_five_cycle_traces.csv` contains the windows displayed in the
main figure. The `cycle_sequence` axis concatenates independently selected
five-cycle windows at 30%, 60% and 100% strain and is not continuous elapsed
time. The figure is a representative feasibility comparison.
