# Figure 4 conductive-network data

This directory contains raw electrical workbooks and strain-resolved SEM images
for the CNT/CB single-layer and CNT/CB--Ag dual-layer architectures. Three
independently fabricated devices were tested per architecture.

`representative_five_cycle_traces.csv` contains the windows displayed in the
main figure. The `cycle_sequence` axis concatenates independently selected
five-cycle windows at 30%, 60% and 100% strain and is not continuous elapsed
time. The figure is a representative feasibility comparison; raw workbooks are
provided so that device-level summaries can be regenerated.
