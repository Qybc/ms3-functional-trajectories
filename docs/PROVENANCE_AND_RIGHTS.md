# Provenance, rights and access boundaries

## Author-generated and included

- numeric Source Data and Supplementary Data tables;
- derived corpus and historical-analysis summaries;
- FS EvidenceQA numeric judgments and author-generated rubrics;
- experimental electrical, adhesion, microscopy and physiological data supplied
  by the study team;
- analysis, validation and demonstration code written for this study;
- the MS3 record schema and illustrative example.

Author-owned code is covered by the BSD 3-Clause License. Author-generated,
redistributable data and documentation are covered by CC BY 4.0.

## Third-party inputs referenced but not redistributed

- publisher PDFs, figures, tables and long article excerpts;
- benchmark content whose distribution is governed by the original benchmark
  licence;
- Qwen2.5 and comparison-model weights or hosted model services;
- third-party source-acquisition tools and institutional-access credentials.

The release uses bibliographic metadata, source pointers and copyright-permitted
derived fields in place of publisher content. Users must obtain third-party
materials from their original sources under the applicable terms.

## Credentials and personal data

No password, API key or access token is included. Released animal-acquisition
files were screened for operator names, local paths and facility identifiers
beyond those required for scientific reporting. This release contains no
human-participant data.

## Licence scope at DOI creation

The repository deposit contains:

1. a BSD 3-Clause licence for author-owned source code;
2. a CC BY 4.0 notice covering only redistributable author-generated data and
   documentation;
3. a third-party notice listing models, benchmarks and software dependencies;
4. the persistent DOI recorded in the repository metadata and manuscript after
   archival deposit.
